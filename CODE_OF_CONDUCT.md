# Code of conduct

Treat contributors respectfully regardless of experience or background. Discuss engineering evidence, question assumptions constructively, and accept corrections. Harassment, discrimination, threats and disclosure of private information are unacceptable.

Maintainers may remove abusive content and limit participation to protect the project. Report concerns privately to a maintainer through an available GitHub private contact channel; do not post another person's private information in an issue. If no private channel is configured, request one without publishing details. No response-time guarantee is claimed.
